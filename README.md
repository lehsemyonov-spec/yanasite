# Лендинг марафона Lobach Design

Одностраничный сайт 3-месячного марафона по продающей инфографике.

## Файлы

- `index.html` — исходник сайта (стили и скрипты внутри файла).
- `img/` — логотипы и картинки, `video/` — видео-отзыв, `fonts/` — шрифты (Unbounded, Manrope, Cormorant Garamond; лицензия OFL).
- `dist/lobach-marafon.html` — **готовый файл одним куском**: картинки и шрифты уже внутри, можно открыть двойным кликом или загрузить на любой хостинг.

После правок в `index.html` пересоберите единый файл:

```bash
python3 tools/build_standalone.py
```

## Что заменить позже

- Видео-отзыв учеников: `video/student-review.mp4`, обложка — `img/student-review-poster.webp`. Чтобы заменить, положите новые файлы под теми же именами и пересоберите.
- Акцентный цвет меняется в одном месте — переменные `--accent*` в начале `<style>`.
